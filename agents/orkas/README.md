# Orkas

## 简介

Orkas 是一款开源、本地优先的 AI 团队桌面应用。用户通过一个对话给出目标，Commander 将目标转成可执行计划，并协调专业 Agent 并行或串行完成复杂工作。

## 核心特性

- **多 Agent 协作**：Commander 负责任务规划、拆分和协调。
- **本地优先**：对话、文件、项目历史和知识资料默认保存在用户设备上。
- **灵活模型接入**：可使用兼容的本地模型端点，也可连接用户选择的远程模型服务。
- **桌面工作流**：覆盖研究、编程、数据分析、文档、演示和视频等工作。

## 典型 Use Case

- **跨领域项目执行**：把调研、分析、文档整理和实现任务交给不同专业 Agent，由 Commander 汇总进展与结果。
- **本地模型团队工作流**：连接兼容的本地模型端点，在桌面应用中组织多个专业 Agent 协作。

## 效果评估

- 开源仓库提供完整项目代码、文档和公开 issue 记录，可用于验证功能范围与维护状态。
- 具体质量、速度和资源占用取决于用户选择的模型、端点和任务复杂度。

## 安装与使用

- macOS 和 Windows 可使用项目发布的桌面安装包。
- Linux 可按仓库文档从源码运行。
- 本地模型需要单独运行兼容的 OpenAI API 端点并在 Orkas 中配置。
